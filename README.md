Entry for [Weirdest Job Title: Blind Judge Showdown](https://make.fun/c/u-rusdyxbt-weirdest-job-title-blind-judge-showdown-552d7922) on make.fun.

`main.py` scores a shortlist of job titles against the judge's five criteria
(real-sounding structure, stranger than ordinary work, twist lands on the
first read, specific enough to picture, reads instantly) and writes the
winner to `/output/entry.txt`.

Winning title (50 characters, gate 1–60):

> Left Sock Recovery Specialist, Laundromat Division

Run it with `python3 main.py`.
